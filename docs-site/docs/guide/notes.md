# Working with Notes

Notes are the core building block of Second Brain. Every piece of knowledge — an idea, article summary, meeting note, or daily log — is a note.

## Creating a Note

- Click **Quick Capture** in the sidebar
- Press `Ctrl+N` / `Cmd+N`
- Navigate to **Notes → New Note**

## Editor Features

The note editor supports:

- **Markdown** with live preview
- **Block-based editing** via the block editor toggle
- **Tags** — add `#tag` anywhere in content, or use the tag field
- **Backlinks** — reference other notes with `[[Note Title]]`
- **Hierarchy** — set a parent note to build a knowledge tree
- **Source URL** — capture where content came from
- **Daily notes** — notes with the daily template get a date-stamped title

## AI Features

| Feature | How to use |
|---------|-----------|
| **Suggest tags** | Click the ✨ button in the tags field |
| **Generate flashcards** | Open a note → Flashcards tab → Generate |
| **Summarize** | Ask Brain about the note: `/ask summarize my note on X` |
| **Auto-connect** | Saved notes are automatically linked to related notes |

## Organizing Notes

- **Tags**: Flat labels for cross-cutting topics
- **Collections**: Curated groups (like notebooks)
- **Hierarchy**: Parent/child tree structure
- **Graph**: Visual exploration of connections

## Note Lifecycle

1. **Capture** → Quick Capture or import
2. **Process** → Add tags, connections, move to collections
3. **Review** → Spaced repetition surfaces notes when needed
4. **Archive/Garden** → Mature notes can be published to your digital garden

## Keyboard Shortcuts

| Shortcut | Action |
|----------|--------|

| `Ctrl+S` | Save note |
