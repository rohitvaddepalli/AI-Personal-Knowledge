# Roadmap

Second Brain is actively developed. Here's what's planned.

## v1.0 — Foundation ✅

- [x] Note CRUD with markdown editor
- [x] Semantic search (ChromaDB + Ollama embeddings)
- [x] Ask Brain RAG interface
- [x] Knowledge graph visualization
- [x] Spaced repetition review
- [x] Collections and hierarchy
- [x] Task tracking
- [x] Flashcard generation (SM-2)
- [x] URL and file import
- [x] Daily digest
- [x] Analytics dashboard
- [x] Digital garden (public notes)
- [x] Multi-provider LLM router
- [x] Docker Compose deployment
- [x] JWT authentication (multi-user)

## v1.1 — Polish & Integrations

- [ ] MCP server — expose notes as tools to Claude/GPT
- [ ] Obsidian real-time sync (folder watch)
- [ ] Notion bi-directional sync
- [ ] CLI tool (`second-brain` Typer CLI)
- [ ] Progressive Web App (offline mode)
- [ ] Mobile-responsive UI improvements
- [ ] Bulk export (Obsidian, HTML, PDF)

## v1.2 — Advanced AI

- [ ] Multi-modal notes (images + OCR)
- [ ] Voice note transcription (Whisper local)
- [ ] Automated knowledge connections (entity extraction)
- [ ] Note templates with AI fill-in
- [ ] Writing assistant mode (expand, rewrite, critique)
- [ ] Research assistant (multi-source synthesis)

## v2.0 — Collaboration

- [ ] Shared vaults (team knowledge base)
- [ ] Commenting and annotations
- [ ] Permission system (viewer/editor/admin)
- [ ] Conflict resolution for concurrent edits
- [ ] Activity feed

## Suggesting Features

Open a GitHub Issue with the `enhancement` label. Upvote existing issues to signal priority.
